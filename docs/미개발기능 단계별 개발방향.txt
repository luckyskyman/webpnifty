✦ Phase 5: 장기 성장 전략 (6주차 이후)

   1. 프리미엄 모델(Freemium) 도입 고려

         * Pro 기능 기획: 광고 제거, 일괄 변환, 워터마크 추가, 이미지 리사이징 등 유료 사용자에게만 제공할 기능을 구상합니다.
         * 결제 시스템 연동: Stripe, Lemon Squeezy 등 결제 처리 서비스 연동을 준비합니다.

   2. 콘텐츠 마케팅을 통한 SEO 강화

         * /blog 경로를 생성하고 "WebP란 무엇인가?", "이미지 최적화 가이드" 등 정보성 콘텐츠를 주기적으로 발행하여 검색 엔진을 통한 자연스러운
           사용자 유입을 증대시킵니다.
  네, 두 개발 계획서 파일을 분석하여 현재 미개발된 기능과 앞으로의 개발 방향, 그리고 수익성 강화 방안을 상세히 브리핑해 드리겠습니다.

  1. 미개발 기능 상세 분석

  개발계획서 수정안.txt를 기준으로 현재 프로젝트 상황과 비교했을 때, 다음과 같은 기능들이 미개발되었거나 보완이 필요한 상태입니다.

  Phase 2: 핵심 기능 구현 (MVP+)

   * 1. 고급 이미지 처리 기능:
       * 웹 워커(Web Worker) 적용: 이미지 여러 개를 동시에 변환할 때 UI가 멈추는 현상을 방지하기 위한 웹 워커 적용이 계획되어 있으나, 현재는
         구현되지 않았습니다.
       * AVIF 포맷 변환 안정화: AVIF 변환 옵션은 추가되었으나, 라이브러리 호환성 문제로 현재 비활성화되어 있어 핵심 기능임에도 불구하고 사용할 수
         없는 상태입니다.
       * 이미지 리사이징 (해상도 조절): 변환 시 사용자가 직접 이미지의 가로/세로 크기를 조절하는 기능이 계획에 있으나 UI 및 관련 로직이 구현되지
         않았습니다.
       * 메타데이터(EXIF) 제거: 이미지의 EXIF 정보를 제거하는 ON/OFF 스위치 기능이 계획에 포함되어 있지만, 아직 구현되지 않았습니다.
       * 프리셋 기능: '웹사이트용', '최대 압축' 등 자주 사용하는 설정을 저장해두고 한 번에 적용하는 프리셋 UI 및 기능이 미구현 상태입니다.

   * 2. 사용자 편의 기능:
       * '모두 ZIP으로 다운로드' 기능: 여러 이미지를 변환한 후, 개별적으로 다운로드하는 기능만 있고 한 번에 ZIP 파일로 묶어 다운로드하는 기능이
         구현되지 않았습니다.

  Phase 6: 장기 성장 전략

   * 1. 프리미엄 모델(Freemium) 도입:
       * 광고 제거, 일괄 변환 개수 무제한, 워터마크 추가 등 유료 사용자에게 제공할 기능들이 기획 단계에만 머물러 있습니다. 이를 위한 사용자 로그인,
         회원 등급 관리, 결제 시스템 연동 등 전체적인 시스템이 구축되지 않았습니다.

   * 2. 콘텐츠 마케팅 확장:
       * /blog와 같은 별도의 경로를 만들어 정보성 콘텐츠를 발행하는 전략이 계획되어 있습니다. 현재 what-is-webp 등의 개별 페이지는 존재하지만, 이를
         체계적으로 관리하고 확장하기 위한 블로그 시스템은 부재합니다.

  2. 미개발 기능 개발 방향 제안 (단계별 로드맵)

  미개발 기능을 바탕으로, 서비스의 완성도를 높이고 수익성을 확보하기 위한 개발 방향을 3단계로 나누어 제안합니다.

  1단계: 핵심 변환 기능 완성 (Core Feature Completion)

  > 목표: 사용자가 이미지 변환 기능을 사용하는 데 불편함이 없도록 핵심 기능을 100% 완성합니다.

   1. AVIF 변환 문제 해결: 현재 가장 시급한 과제입니다. browser-image-compression 라이브러리 외에 다른 클라이언트 사이드 AVIF 변환 라이브러리(예:
      squoosh.app에서 사용하는 라이브러리)를 리서치하고 적용하여 기능을 안정화합니다.
   2. 고급 옵션 추가: 이미지 리사이징, EXIF 데이터 제거 옵션을 EditStep.tsx 컴포넌트에 UI로 추가하고, useImageConverter.ts 훅에 관련 처리 로직을
      구현합니다.
   3. 웹 워커 도입: 이미지 변환 로직을 웹 워커로 분리하여, 대용량 또는 다수의 이미지 변환 시에도 UI가 멈추지 않고 부드럽게 동작하도록 사용자 경험을
      개선합니다.

  2단계: 사용자 편의성 극대화 (UX Maximization)

  > 목표: 잘 만든 핵심 기능을 사용자가 '매우 편리하게' 사용할 수 있도록 부가 기능을 구현합니다.

   1. ZIP 일괄 다운로드 기능 구현: jszip과 같은 라이브러리를 사용하여, 변환된 모든 이미지를 클릭 한 번으로 ZIP 압축하여 다운로드하는 기능을
      ResultStep.tsx에 추가합니다.
   2. 프리셋 기능 구현: 자주 사용하는 품질, 포맷, 리사이징 설정을 '프리셋'으로 저장하고 불러올 수 있는 기능을 구현하여 사용자의 반복적인 작업을
      줄여줍니다.

  3단계: 수익 모델 고도화 및 장기 성장 기반 마련

  > 목표: 안정적인 수익 창출과 지속 가능한 성장을 위한 기반을 다집니다.

   1. 사용자 인증 시스템 완성: 현재 구현된 NextAuth.js 기반 로그인/회원가입 기능을 안정화하고, 소셜 로그인(Google, GitHub 등) 기능을 추가하여 사용자
      접근성을 높입니다.
   2. 프리미엄 기능 기획 및 아키텍처 설계:
       * 무료/유료 사용자 역할(Role) 구분: Prisma 스키마에 사용자 역할을 정의하고, 특정 기능에 접근할 때 역할을 확인하는 로직을 추가합니다.
       * 결제 시스템 연동 준비: Stripe 또는 Lemon Squeezy 연동을 위한 기본 환경을 설정하고, 결제 페이지 라우팅 및 UI를 설계합니다.
   3. 블로그 시스템 도입: Contentlayer 또는 Velite와 같은 라이브러리를 도입하여, Markdown 파일 기반의 정적 블로그를 구축합니다. 이를 통해 SEO에
      유리한 콘텐츠를 효율적으로 발행하고 관리할 수 있습니다.

  3. 수익성 증대를 위한 발전 방향 제안

  기존 계획을 넘어, WebPnifty를 단순한 변환 툴이 아닌 고수익 전문 서비스로 발전시키기 위한 추가 아이디어를 제안합니다.

  1. API 서비스 제공 (B2B 모델)

   * 웹사이트에서 제공하는 이미지 변환 기능을 API 형태로 제공하여 개발자나 기업 고객을 유치합니다. 사용량 기반(예: 월 10,000회 변환까지 무료, 이후
     유료)의 요금제를 도입하여 새로운 B2B 수익원을 창출할 수 있습니다.

  2. AI 기반의 특화 기능 개발 (프리미엄 기능)

   * AI 배경 제거: 사용자가 업로드한 이미지의 배경을 AI를 이용해 자동으로 제거해 주는 기능을 프리미엄 서비스로 제공합니다.
   * AI 스마트 리사이징: 이미지의 주요 피사체를 AI가 인식하여, 잘리지 않게 자동으로 비율을 조절하며 리사이징하는 '콘텐츠 인식 채우기'와 유사한
     기능을 제공합니다.
   * 이러한 AI 기능들은 높은 부가가치를 가지므로, 기존 프리미엄 모델보다 더 높은 가격의 요금제를 책정할 수 있습니다.

  3. 워크플로우 자동화 기능

   * 사용자가 '이미지 업로드 → WebP 변환 → 800px로 리사이징 → 워터마크 추가'와 같은 일련의 작업을 하나의 '워크플로우'로 저장해두고, 이후에는 파일을
     올리기만 하면 자동으로 모든 과정이 처리되도록 하는 기능을 제공합니다. 이는 전문적으로 이미지를 다루는 사용자들에게 매우 매력적인 프리미엄
     기능이 될 것입니다.

  이러한 방향으로 개발을 진행한다면, WebPnifty는 단순 광고 수익에 의존하는 사이트를 넘어, 강력한 기능을 바탕으로 충성도 높은 사용자와 안정적인
  유료 수익을 확보하는 전문적인 웹 서비스로 성장할 수 있을 것입니다.
