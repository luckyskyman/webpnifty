 미구현 기능 현황 (재분석)

  1. 새로운 구현이 필요한 기능

  아래 기능들은 아직 코드 기반이 없어 새로 개발해야 합니다.

   * 웹 워커(Web Worker) 적용: 이미지 변환 시 UI 멈춤 현상을 막기 위한 웹 워커는 아직 useImageConverter.ts에 적용되어 있지 않습니다.
   * AVIF 포맷 지원: 변환 로직(useImageConverter.ts)과 설정 UI(EditStep.tsx) 모두 WebP 포맷만 처리하도록 되어 있어, AVIF 포맷을 지원하려면 로직과 UI 양쪽 모두에 기능 추가가 필요합니다.
   * 고급 변환 옵션 (메타데이터 제거, 리사이징, 프리셋): EditStep.tsx에 품질 슬라이더 외에 다른 고급 옵션(EXIF 제거 스위치, 해상도 조절 입력창, 프리셋 버튼)은 아직 존재하지 않습니다.
   * '모두 ZIP으로 다운로드' 기능: ResultStep.tsx에 변환된 모든 파일을 한번에 ZIP으로 다운로드하는 기능은 아직 구현되지 않았습니다. jszip과 같은 라이브러리를 이용한 개발이 필요합니다.
   * 블로그 시스템 구축: 현재 구현된 정보성 페이지들(what-is-webp 등)은 개별적인 페이지입니다. 지속적인 콘텐츠 발행을 위한 동적인 블로그(/blog) 시스템은 아직 구축되지 않았습니다.

  2. 구현은 되었지만, 화면에 연결되지 않은 기능

  가장 중요한 부분입니다. 말씀하신 대로, 이미 만들어졌지만 아직 사용자가 볼 수 없는 기능이 있었습니다.

   * 전/후 비교 뷰어 (`ImageComparator.tsx`):
       * 현황: 원본과 변환 후 이미지를 슬라이더로 비교하는 UI 컴포넌트(`ImageComparator`)는 이미 완성되어 있습니다.
       * 남은 작업: 현재 이 컴포넌트는 ResultStep.tsx의 결과 목록 어디에도 연결되어 있지 않습니다. 따라서, 결과 목록의 각 항목에 '비교하기' 버튼을 추가하고, 이 버튼을 클릭했을 때 해당 이미지의 원본/결과물을
         ImageComparator 컴포넌트를 통해 보여주는 작업(예: 모달 창으로 띄우기)이 필요합니다.

  3. 기능 개선이 필요한 기능

  기본적인 형태는 있으나, 계획서의 목표를 달성하기 위해 개선이 필요한 기능입니다.

   * 변환 진행 상태 표시: 현재 전체 변환 과정에 대한 하나의 진행률 막대만 표시됩니다. 이를 개선하여 여러 파일을 변환할 때 각 파일별로 개별 진행률을 보여주면 사용자가 훨씬 더 상세한 피드백을 받을 수 있습니다.
   * 프리미엄 모델(Freemium) 확장: '관리자' 기능은 파일 개수 제한을 없애는 첫 단계입니다. 앞으로 광고 제거, 워터마크 추가 등의 유료 기능을 만들고, 이를 위한 결제 시스템을 연동하는 작업이 필요합니다.

  ---

  정리하자면, 이미지 비교 뷰어는 UI 컴포넌트 개발은 끝났으니 화면에 연결하는 작업을 하면 바로 사용자가 쓸 수 있는 상태입니다.

  가장 빠르게 성과를 볼 수 있는 '이미지 비교 뷰어 화면에 연결하기' 작업부터 진행해볼까요?
